# 阶段 21：设计风格调研 + 可插拔主题系统

> 用户要求：调研 getdesign 网站上的设计风格，选出适合英语学习网站的；并以**主题形式可插拔**更新。

## 一、getdesign.md 调研

getdesign.md 是一个 **DESIGN.md 集合**（300+ 个真实网站的设计系统分析），给 AI 编码代理用，每份包含：colors / typography / rounded / spacing / shadows 等完整设计 tokens。用 CLI 可直接拉取：`npx getdesign@latest add <site>`。

### 候选对比（按英语学习网站契合度）

| 风格 | 核心特征 | 契合度 | 评价 |
|---|---|---|---|
| **Claude** | 暖奶油底 + 陶土珊瑚主色 + 衬线大标题 + 深色产品面 | ⭐⭐⭐⭐⭐ | 与现有温暖阅读感同源，改造最小 |
| **Notion** | 白纸感 + 近黑 Inter + 单一自信蓝 + 多彩贴纸 | ⭐⭐⭐⭐ | 笔记/学习场景完美，但主色是大改动 |
| **Mintlify** | 阅读优化 + 绿点缀 + 侧边栏文档布局 | ⭐⭐⭐ | 偏开发者文档 |
| **WIRED** | 纯黑白 + 衬线长阅读 + 报纸感 | ⭐⭐ | 长阅读一流但太冷峻 |

**结论**：Claude 默认（改造成本最低、气质最对），Notion 可选（不同气质）。

## 二、可插拔主题系统

### 设计

现有 `Theme`（light/dark/system）是**明暗维度**；新增 `Palette`（claude/notion）是**配色/气质维度**。两维正交，可自由组合。

```
html[data-palette="claude"]  → 默认（index.css :root 内联，无需显式标记）
html[data-palette="notion"] → 覆盖块（index.css 末尾）
```

CSS 变量（--background/--primary/--accent/--chart-* 等）作为主题 token，两套 palette 各自定义。加主题 = 加一个 `html[data-palette="xxx"]` 覆盖块，**完全可插拔**。

### 为什么用内联而非独立文件 @import

最初把 Notion 放独立 CSS 文件用 `@import` 引入，但发现 **CSS 规范要求 @import 必须在所有规则之前**，放在变量定义之后会被忽略，导致主题不生效。改用**直接在 index.css 末尾内联 `html[data-palette]` 块**（高权重选择器确保覆盖 :root），简单可靠。

### 实现

- `lib/theme.ts`：新增 `Palette` 类型 + `PALETTES` 配置 + `getPalette/setPalette/applyPalette`，持久化到 `de.palette.v1`
- `SiteHeader`：加 Palette 切换按钮（claude↔notion 循环），与明暗按钮并列
- `SettingsPage`：新增"外观"区块——配色风格（温暖/专注，带色块预览）+ 明暗模式（浅色/深色/跟随系统）
- Claude 默认色板：奶油底 `oklch(0.98 0.006 82)`、陶土珊瑚 `oklch(0.62 0.11 32)`
- Notion 色板：纯白底 `oklch(0.997 0 0)`、自信蓝 `oklch(0.5 0.16 250)`

### 踩坑记录

1. **@import 位置限制**：CSS @import 必须置顶，放变量定义后无效 → 内联合并。
2. **lucide `Palette` 图标与类型同名冲突**：`Palette` 既是类型又是图标 → 图标 `as PaletteIcon`。
