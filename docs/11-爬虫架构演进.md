# 阶段 11：爬虫架构演进（可插拔来源 + 风控 + 卫报/大西洋）

> 本阶段把阶段 10 的单一 VOA 爬虫重构成**可插拔的 provider 架构**，新增卫报、大西洋月刊两个来源，
> 并为每个来源接入**基础风控**（限速 + 指数退避 + 熔断），解决"内容来源单一、VOA 文章太老"的问题。

## 背景思考

阶段 10 只有 VOA 一个来源，用户发现 **VOA 文章偏老**（不少是 2024/2025 年的），内容也不够新锐。
用户要求把卫报（The Guardian）、大西洋月刊（The Atlantic）加进来，同时对爬虫做**解耦 + 可插拔**，并加**风控机制**。

这里有个绕不开的坎：**卫报和大西洋月刊都有版权**（卫报 ©、大西洋月刊是付费墙订阅制）。
我先做了一次风险提醒（AGENTS 里也写过"真实外刊版权绕行"），用户明确选择**接受风险抓全文存储**。
我按用户决定实现，同时在文档里把风险写清楚，将来若真用于公开服务，需要自行评估合规。

卫报好在有**官方 Open Platform API**（合法、免费额度），我们没用它而选了直接抓全文，是用户拍板的路线。

## 完成内容

- **可插拔架构** `backend/app/crawler/`：
  - `base.py`：`CrawlerProvider` 抽象基类 + `RawArticle` 数据模型。新刊物只需继承、实现 `fetch_articles()`，并在 `providers/__init__.py` 里 `register()` 一行注册
  - `registry.py`：来源注册表（register/get/all/sources）
  - `providers/`：`voa.py` / `guardian.py` / `atlantic.py` 三个 provider，各管各的列表页、正文解析、难度、标签
  - `run.py`：统一遍历已注册来源，清洗/去重/短文过滤/入库；可指定 `sources` 只抓某个来源
- **风控机制** `throttle.py`：
  - `RateLimiter`：每源最小请求间隔（VOA 1s、卫报 1.5s、大西洋 3s——反爬越严的间隔越大）
  - **指数退避**：请求失败按 `2^n` 秒重试（上限 30s）
  - `CircuitBreaker`：连续失败达阈值（默认 5 次）后**熔断**，本批直接跳过该来源，等冷却期后再试——某个源被反爬拦住时不影响其他源
  - `SafeFetcher`：封装限速 + 退避 + 熔断，provider 只需 `self.soup(url)` / `self.fetch_raw(url)`
- **卫报 provider**：5 个 section（world/science/technology/business/environment）→ 文章链接 → 正文 `div[data-gu-name="body"]`（fallback `.article-body-commercial-selector`）；难度 advanced
- **大西洋 provider**：5 个 section；**正文在 `__NEXT_DATA__` JSON 里**（Next.js GraphQL urqlState，`article.content[].innerHtml`），从 HTML 的 `<script id="__NEXT_DATA__">` 提取并解析，绕开静态 HTML 无正文的问题
- **接口**：`GET /api/crawl/sources`（列出可抓来源）、`POST /api/crawl?source=`（可指定/全量，返回各源统计）
- **前端**：来源类型扩展（seed/voa/guardian/atlantic/local）+ `sourceLabels` 标签映射（未知来源回退显示原名，**天然可插拔**）；筛选 tabs **动态生成**（后端注册了什么源，前端就自动出现对应 tab）；抓取按钮改通用 `/api/crawl`

## 技术决策及理由

1. **provider 抽象 + 注册表**：新增来源 = 一个文件 + 一行注册，不动 run/路由/前端。这是"可插拔"的关键。
2. **风控做进基类**：限速/退避/熔断统一在 `SafeFetcher`，每个来源按反爬强度配不同 `min_interval` 和 `failure_threshold`（大西洋最敏感：3s 间隔、3 次失败即熔断）。
3. **熔断而非报错**：某源被 Cloudflare 拦（大西洋一度如此）时，整批跳过并记日志，VOA/卫报照常入库——**单个来源的失败不该拖垮全局**。
4. **大西洋走 `__NEXT_DATA__`**：付费墙站点通常不把正文渲染在静态 HTML（正文在 GraphQL/JSON），纯 HTML 选择器会扑空。探测确认后改从 JSON 提取，实测 5 篇 1088~3476 词全部入库。

## 踩坑记录

- **卫报链接是相对路径**：section 页提取的是 `/world/2026/aug/03/...` 无 scheme，`requests.get` 直接报 `Invalid URL: No scheme supplied`。修复：拼上 `https://www.theguardian.com` 前缀。
- **大西洋正文不在 HTML**：`div.article-body`/`div#article-body` 都不存在，页面是 Next.js，正文藏在 `__NEXT_DATA__` 的 GraphQL 状态里。用正则提取 JSON、遍历 urqlState 找到 `article.content[].innerHtml` 才拿到正文。
- **大西洋链接筛选条件猜错**：一开始按 `/ideas/archive/` 匹配（旧 URL 结构），实测新结构是 `/ideas/2026/08/slug/id/`，改成"section 后跟 4 位年份数字"才匹配到。
- **可复用上一阶段的坑**：WSL mtime 精度导致 vite 喂旧代码、bash 超时连带杀后台服务，本阶段再次出现，均靠"重启 + 清缓存 + 短命令分步"解决。
