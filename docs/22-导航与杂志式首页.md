# 阶段 22：导航壳层重构 + 杂志式首页

> 用户反馈：光改配色解决不了问题，页面结构差点意思。确认方向——**导航布局**是主要问题，首页走**杂志式布局**。

## 一、问题诊断

**旧导航**：一条 14px 高的顶部栏塞了 6 类东西（logo/文章/个人中心/配色/明暗/登录退出），没有分区；全站 `max-w-3xl`（768px）过窄；个人中心横向 tab 叠在顶部栏下，前台/后台没有场域感。

**旧首页**：所有内容在一根垂直轴上堆叠（标题→今日推荐→为你推荐→搜索→难度→来源→文章列表），无信息层级、无分组、单列到底。

## 二、导航壳层重构

**方案（用户确认）：顶部栏 + 用户下拉菜单，画布加宽。**

新顶部栏（`SiteHeader` 重构，h-16）：
- **左**：logo + 主导航（文章）
- **中**：搜索框（提交跳 `/?q=...`，首页读取 URL 参数回填）
- **右**：配色切换 + 明暗切换 + 用户下拉菜单

**用户下拉菜单**：收纳个人中心全部 6 个入口（我的学习/生词本/复习/笔记/设置/添加文章）+ 退出登录。点击外部关闭（自定义实现，未引 dropdown 库）。

**画布加宽**：前台列表/个人中心从 `max-w-3xl` → `max-w-5xl`；阅读页保持窄（`max-w-3xl` 阅读体验更好）。

## 三、杂志式首页

**布局（用户确认：主推 + 网格分栏）：**

```
┌────────────────────────────────────┐
│ 页头（标题/副标题 + 随机/同步按钮）       │
├────────────────────────────────────┤
│ 今日推荐 HERO（大卡、3xl 标题、渐变底）  │
├──────────────────┬─────────────────┤
│ 左栏：为你推荐(2列)│ 右栏：筛选侧栏     │
│ 搜索工具条        │  难度 / 来源      │
│ 文章网格（2列）    │  （sticky 吸附）   │
│ 加载更多          │                 │
└──────────────────┴─────────────────┘
```

- **HERO 主推**：今日推荐放大成整行大卡（3xl 衬线标题、渐变背景、hover 放大）
- **左栏网格**：为你推荐 2 列 + 文章网格 2 列（`sm:grid-cols-2`），卡片紧凑化
- **右栏筛选**：桌面端 sticky 侧栏（难度/来源分组）；移动端变横向滚动条
- **ArticleCard 适配**：标题/摘要 line-clamp，标签精简为难度+来源+时间，卡片等高

## 四、技术决策及理由

1. **下拉菜单不用 shadcn Dropdown**：项目没装该组件，自定义实现（点击外部关闭 + aria 属性）依赖更少、样式可控。
2. **搜索参数走 URL**：`/?q=fox` 可分享、可刷新保持，首页 `useSearchParams` 读取回填。
3. **阅读页保持窄**：长文阅读在窄列更舒适，列表/导航用宽画布，按场景差异化。

## 五、验证（CDP，桌面视口）

- 用户菜单：我的学习/生词本/退出登录可见，点击外部关闭
- 顶部搜索 `fox` → 跳 `/?q=fox`，文章数 13→2（过滤生效）
