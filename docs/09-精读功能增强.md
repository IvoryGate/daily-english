# DailyEnglish 阶段 09：精读功能增强（点查 + 生词本 + 自我精读）

> 本文档是「阶段 09 精读功能增强」的详细开发记录，口语化为博客积累素材。
> 起因：分析了两个竞品（englio.ai、engread.top）后确定的功能补充。

## 1. 背景：竞品分析驱动的功能补充

MVP（阶段 03~08）做完后，看了两个竞品网站：

- **engread.top（ReadEng）**：考研外刊精读。核心是外刊来源管理 + 难度筛选（四级/六级/考研/超纲）+ **生词本**。
- **englio.ai（AI Level English）**：AI 驱动分级阅读。核心是 AI 改写 6 级难度 + **逐句精读** + **逐词点查**（37,000 朗文词典）+ **FSRS 闪卡复习**。

共同模式（行业标配）：**精读辅助**（点词查义）+ **词汇沉淀**（生词本/闪卡）+ **内容来源**（外刊）。

对照我们的项目：只有"列表 + 详情 + 4 篇 Aesop"，精读和沉淀能力为零。本次补充三个功能：

1. **逐词点查**：点击正文任意单词，弹层显示音标/词性/释义/例句
2. **生词本 + 闪卡复习**：阅读中收藏生词，到期提醒复习
3. **自我精读**：粘贴任意英文文章（真实外刊入口），本地保存后可精读

## 2. 关键技术决策

### 决策 1：全程 localStorage，不突破"无账号/只读 API"边界

生词本、闪卡、自我精读本来都需要持久化。要持久化就得要么加账号系统、要么给后端加写接口——这两个都违背 MVP 的"无登录、只读接口"设定。

**用 localStorage 解决**：数据量小（生词、几篇文章）、单用户，localStorage 完全够用，而且不碰后端、不引入账号。代价是换浏览器/清缓存会丢，对个人学习工具可接受。这是"用最小的架构增量换取功能增量"的典型取舍。

### 决策 2：词典用免费 API + localStorage 缓存

点查需要词典数据。调研了免费无 key 的词典 API：`dictionaryapi.dev`（Free Dictionary API），返回音标、词性、释义、例句，够用。

**缓存策略**：查过的词存 localStorage。好处：① 重复点击秒开不重复请求；② 网络不可用时查过的词仍能看；③ 为将来做迷你离线词典留了口子。

### 决策 3：正文分词渲染

点查的难点是"点击单词"——正文是纯文本，不能直接点。做法是把正文按 token 拆开渲染：

```ts
// 保留捕获组，英文单词（含撇号/连字符）切出来，其余按标点/空格原样保留
text.split(/([A-Za-z][A-Za-z'-]*)/g)
```

单词渲染成可点击的 `<button>`，标点渲染成普通 `<span>`。点击单词 → 记录点击坐标 → 在该位置弹固定定位的释义卡片。

### 决策 4：闪卡用"简单间隔"而非完整 FSRS

竞品用 FSRS 算法，但我们不引第三方库、不过度设计。实现**三级间隔**：

- 不认识 → 重置为"新词"，1 天后复习
- 认识 → stage+1，间隔 1 天 → 3 天 → 7 天，到"已掌握"不再频繁出现

用 `nextReviewAt` 时间戳判断是否到期，到期的词进 `/review` 复习队列。够用、可解释、后续想换 FSRS 也容易。

### 决策 5：本地文章用负数 id + source 字段区分来源

后端文章 id 是正数自增。本地文章用 `-(Date.now())` 做负数 id，天然唯一、绝不与后端冲突。`Article` 加 `source: 'server' | 'local'` 字段，`fetchArticles` 合并两者，`fetchArticle` 按 id 正负分流。页面无感知，列表/详情/点查全部天然支持本地文章。

### 决策 6：真实外刊怎么来（版权绕行）

Guardian/BBC/NYT 全文有版权，不能爬来内置。方案：**用户自供内容**——`/new` 页粘贴任何英文文章，保存到本地，然后就能精读/点查/收生词。这就是"真实外刊精读"的入口，内容合法（用户自供）、实现零后端改动。RSS 外刊速览（抓标题摘要）作为后续可选项。

## 3. 实现的结构

```
src/
├── lib/
│   ├── storage.ts        # localStorage 封装：本地文章/生词本/词典缓存
│   └── dictionary.ts     # 查词：缓存 → 在线 API → 解析
├── components/
│   └── ArticleReader.tsx # 正文分词渲染 + 点查弹层（WordPanel）
├── pages/
│   ├── VocabularyPage.tsx # 生词本列表（阶段/来源/待复习标记/删除）
│   ├── ReviewPage.tsx     # 闪卡复习（翻卡、认识/不认识、进度）
│   └── NewArticlePage.tsx # 粘贴文章（标题/正文/难度）
```

路由新增 `/vocabulary`、`/review`、`/new`，`SiteHeader` 加导航（文章/生词本/复习/添加文章），详情页正文换 `ArticleReader`，本地文章可删除。

## 5. 踩坑记录

| 坑 | 现象 | 解决 |
|---|---|---|
| tsc 找不到 | `tsc: not found`，node_modules 整个丢失（deploy.sh 的 npm ci 期间） | `npm install` 重新恢复 |
| 类型推断报错 | `Array.isArray() && expr?.text` 返回值类型混入 `false` | 抽变量先判 `isArray` 再取值 |
| shadcn 组件 | 新页面用到 select/input/label/textarea | `npx shadcn add`，tsconfig 修复后正确写入 src/ |
