# 阶段 18：面向初学者的学习体系（学习路径 + 激励 + 统计 + 辅助）

> 用户反馈：功能还行，但作为面向 beginners 的英语学习网站，还远远不到可以部署的程度——需要更丰富的辅助功能、更清晰的学习路径、更有效的激励、学习统计。这一阶段按「地基 → 激励 → 学习路径 → 辅助」四个模块落地。

## 一、需求拆解与设计

| 模块 | 用户诉求 | 落地功能 |
|---|---|---|
| 学习路径 | "从哪开始、下一步读什么" | 等级体系（Lv1~5）+ 首页"为你推荐"按级推荐 |
| 激励闭环 | 有目标、有反馈、想坚持 | 每日目标 + 连续打卡 streak + 成就徽章 |
| 学习统计 | 看到成长 | 热力图 + 累计复习 + 等级积分 + 今日进度 |
| 辅助功能 | 读得懂 | 整句翻译 + 文章重点词前置/标注 |

**打卡标准**（用户确认）：**读 + 复习双达标**（每日阅读 ≥ 目标篇数 且 每日复习 ≥ 目标词数），目标可在设置页配置。

## 二、数据模型（地基）

新增三张表 + User 扩展：

- **`review_history`**：一次复习作答一行（user_id / word / rating / reviewed_at）。驱动 streak、热力图、复习趋势、成就。
- **`achievements`**：已解锁徽章（user_id / key，唯一约束防重复）。
- **User 加列**：`daily_read_goal`、`daily_review_goal`（默认各 1）。
- `migrate()` 补 User 两列（SQLite 无 IF NOT EXISTS 列语法，沿用幂等 ALTER）。

`gamification.py` 是纯函数层，便于测试：
- **等级**：积分 = 读篇数×10 + 生词数×5 + 复习次数×1 → Lv1~5（入门/进阶/熟手/高手/大神）
- **streak**：从今天往回数连续达标天数，今天未达标不算断
- **成就**：9 个徽章（first_read/read_10/read_50/vocab_20/vocab_100/review_50/streak_3/streak_7/streak_30）

## 三、后端接口

- `POST /api/me/reviews`：记录复习，顺带评估解锁新成就（复习是高频动作）
- `GET/PUT /api/me/goals`：每日目标读写
- `GET /api/me/stats`：聚合——等级/积分/streak/今日进度/成就列表/182 天热力图
- `GET /api/dict/translate?text=`：整句英译中（Google gtx 优先，MyMemory 兜底，30 天缓存）

## 四、前端

- **ReviewPage**：作答时 POST 复习记录（不阻塞复习流程）
- **Dashboard 大改版**：等级卡（Lv + 积分 + 提示）+ streak + 今日目标双进度条 + 累计统计卡（新增"累计复习"）+ GitHub 风格热力图 + 成就徽章墙
- **SettingsPage**：新增"每日目标"设置区块
- **ArticleListPage**：登录后顶部"为你推荐"（按等级映射难度，优先未读 3 篇）
- **ArticleDetailPage**：新增"本文章重点词"区块（提取高频实词，可发音/收藏）+ 段落级翻译按钮
- `lib/keywords.ts`：停用词过滤 + 词频提取

## 五、踩坑记录

**时区 bug（重要）**：后端存时间用 `datetime.utcnow()`（UTC），但 `day_progress`/`heatmap` 用本地时间（`datetime.now().date()`）判断"今天"，导致跨日偏差 8 小时——本地时间早上 8 点前学习会被算成"昨天"。修复：**天数判断统一用 UTC**（`datetime.utcnow().date()`），与存储一致。影响面：仅凌晨跨日边界，对个人学习可接受。

**UPSERT 造成"今天没数据"假象**：测试时 `PUT /reading/5` 没有新增记录——因为文章 5 已有历史记录，upsert 变成了更新旧记录的 progress，read_at 保持旧值。排查时一度以为是 bug。**教训：造测试数据要用从未读过的文章 id。**

**路由顺序**：`GET /api/dict/{word}` 是 catch-all，`/translate` 若声明在它之后会被吞掉。FastAPI 按声明顺序匹配，翻译路由必须放在 `{word}` **之前**。

## 附：词汇量曲线 + 复习趋势图

上一版只做了"生词计数"，用户明确要"词汇量估算曲线"和"复习趋势图"的可视化。这一版补上两个图表。

### 词汇量增长曲线（`vocabulary_curve`）

- **算法**：`vocabulary_entries.added_at` 按天分组计数，逐天**累计**成曲线——诚实呈现"生词量随时间增长"。
- **已掌握词数**（`mastered_vocab`）：FSRS 卡 `state >= 2 且 reps >= 3` 视为掌握，在曲线标题旁显示"共 N 生词，其中已掌握 M 词"。
- 前端用**无依赖 SVG 折线图**（`LineChart` 组件），轻量不引第三方图表库。

### 复习趋势图（`review_trend`）

- `review_history.reviewed_at` 按天分组，近 30 天每日复习次数。
- 前端用**无依赖 SVG 柱状图**（`BarChart` 组件），每根柱带 `title` 悬浮提示。

### 踩坑记录

**组件名与 lucide 图标冲突**：自定义 `LineChart` 组件和 `lucide-react` 的 `LineChart` 图标同名，TS 直接报 import 冲突。修复：图标 import 时 `as LineChartIcon` 重命名。**教训：自定义组件名尽量避开库导出名，或统一 `Icon` 后缀。**

- CDP：Dashboard 渲染两个 SVG（aria-label = 词汇量增长曲线 / 每日复习次数柱状图）+ "已掌握"文本
