# 阶段 27：学习路径（词汇画像驱动的文章阶梯）

## 背景思考

阶段 26 给生词做了 8 级分级（初中→超纲），但发现一个问题：**分级只服务了"重点词标注"，没有真正用于"推荐读什么"**。首页"为你推荐"仍按 author 预设的三档难度（beginner/intermediate/advanced）过滤，粒度极粗，也没法回答"我现在该读哪个难度档"。

用户在做产品批评时明确：**P1 学习路径 = 让"读什么"有逻辑阶梯**。这轮的目标：把"词汇分级"从"标注"升级为"文章打分"，做成一条从易到难的阅读路径。

## 完成内容

### 1. 文章词汇画像（后端核心）

新增 `backend/app/crawler/article_level.py`：
- `vocab_profile(content)`：正文 → 词形归并 → 逐词标注 8 级 → 统计各级词数
- 两个输出：
  - `vocab_level`：**累计词量首达 50% 所需的级别**（「读懂一半词」需达到的档）
  - `vocab_score`：各级权重（低→高 0~7）加权平均，归一化 0~100（越小越易）
- `Article` 模型加 `vocab_level` / `vocab_score` 两列 + `migrate()` 幂等补列
- `scripts/backfill_article_level.py` 回填已有文章（**50 篇**全部算好）

### 2. 词表数据修复（重要）

生成新词表时意外发现旧 `word_lists.json` 有问题：
- 旧表 junior 仅 849 词，**把 `run`/`sleep`/`small`/`school` 这些基础词漏掉了**（被归到 tem8/advanced）
- 原因：旧表是用当时残缺的 ECDICT 子集生成的，覆盖稀疏 → 简单文章级别虚高（伊索寓言竟成"最难"）

修复：
- 重新下载完整 ECDICT（63M），`gen_word_lists.py` 重新生成 → 词数大增：junior 849→1603、senior 2021→3677……
- `run`/`school` 等正确落回 junior/senior；文章画像立即合理：狼来了 5.4 junior（最易）→ 最新影评最难
- 保留专八档：`/tmp/tem8.txt` 缺失时从旧产物回填 tem8（gen 脚本增强）

修复后分布：50 篇文章 28 篇 junior + 22 篇 senior，vocab_score 5~33，区分度合理。

### 3. 后端接口

- `GET /api/articles` 新增参数：
  - `vocab_level=<级别>`：过滤指定词汇级别
  - `sort=easiest`：按词汇分升序（最易在前）
- `ArticleSummary` 响应新增 `vocab_level` / `vocab_score`

### 4. 前端学习路径页 `/path`

- 前置：`App.tsx` 加 `/path` 路由；`SiteHeader.tsx` 主导航加「学习路径」
- `lib/learningPath.ts`：8 级标签 + 用户等级(Lv1~5) → 建议词汇区间映射 + 容错上限
- `pages/LearningPathPage.tsx`：
  - 8 级词汇阶梯卡片（高中/四级/六级/雅思/托福/专八/超纲）
  - 登录后显示「你的进度」（LvX + 建议区间 + 最多读到哪档）
  - 点击某档加载该档文章（按词汇量从易到难）；URL 同步 `?level=xxx`
- `api/articles.ts` 新增 `fetchArticlesByVocab(level)`

## 技术决策及理由

1. **用词汇画像而非可读性公式**：Flesch 等只看句子长度/音节，不含词汇难度语义。用"读懂一半词所需级别"更贴合学习场景（我们知道每个词的档位）。
2. **50% 累计作为词汇级别**：「读懂一半内容词」是进入一篇文章的合理门槛；比均值更抗个别超纲词干扰。
3. **词表重新生成而不修补**：旧表数据源残缺是根因，直接换完整 ECDICT 一次到位，避免在坏数据上打补丁。
4. **vocab_level 是过滤级别，vocab_score 是排序分**：分开让「筛选」与「排序」各司其职。

## 踩坑记录

- **ECDICT 覆盖稀疏**：考试大纲词表不含 `run`/`sleep` 等基础词，旧表把它们误判为专八 → 简单文章虚高。换完整数据 + 重生成解决。
- **365 温度问题：vite 5173 被旧进程占用**：kill 旧 node（pid）后新代码才上 5173，否则 CDP 验证到的是 5174 旧实例。
- **`--harmony` 后台启动挂起**：守规则 `(setsid nohup … & disown)` 包一层子 shell 让命令立即返回，避免 bash 工具卡 120s。
