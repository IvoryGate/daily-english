# 阶段 24：正文页优化（重点词轮播 + 整篇翻译 + 收藏 + 排版）

> 用户要求优化文章正文页：重点词轮播卡片（读音释义丰富展示）、逐段翻译（可收起）、正文页收藏文章、排版优化。先做技术分析，翻译要快准。

## 一、技术分析

| 需求 | 方案 |
|---|---|
| 重点词轮播卡片 | 横向滑动卡片组，每张卡：美英音标+发音+释义+收藏，左右箭头切换 |
| 整篇逐段翻译 | **批量接口**：多段合并一次请求（Google 保留分隔符）→ 按段拆分 |
| 正文页收藏 | 工具栏加收藏按钮（复用 bookmarks API） |
| 排版 | 段落间距、字号行距微调 |

### 翻译"快"的关键发现

**Google gtx 保留换行/分隔符**。测试确认：用 `@@@SEP@@@` 分隔多段合并翻译，分隔符原样保留、各段译文不混。因此**整篇 N 段 = 1 次 HTTP 往返**（0.66s 实测 3 段），比逐段请求（N 次往返）快一个数量级。

## 二、后端：批量翻译接口

`POST /api/dict/translate-batch`：
- `texts: list[str]`（≤30 段，总字数 ≤5000）
- 用 `@@@SEP@@@` 拼接 → Google 一次翻译 → `split(_SEP)` 拆回
- 段数不足时补空串对齐；Google 失败回退逐段 MyMemory
- 各段单独缓存 30 天（复用 `_TRANS_CACHE`）

## 三、前端

- **`KeywordCarousel`**：重点词轮播（滑动卡片组）。每张卡懒加载词典详情（`lookupWord`），显示美英音标、发音（有道音频）、释义（前 3 条）、收藏生词；左右箭头 + 进度指示。
- **`ArticleReader` 重构**：
  - "翻译全文/收起全文翻译"工具条 → `translateBatch` 一次翻译所有段落
  - 每段下方显示译文（灰底块），带"译文"收起/展开按钮（可逐段收起）
- **`ArticleDetailPage`**：重点词 pills → KeywordCarousel；工具栏加"收藏/已收藏"按钮。
- `lib/translate.ts`：批量翻译 API 封装（空段补位对齐）。
