# 阶段 24：正文页优化（重点词轮播 + 整篇翻译 + 收藏 + 排版）

> 用户要求优化文章正文页：重点词轮播卡片（读音释义丰富展示）、逐段翻译（可收起）、正文页收藏文章、排版优化。先做技术分析，翻译要快准。

## 一、技术分析

| 需求 | 方案 |
|---|---|
| 重点词轮播卡片 | 横向滑动卡片组，每张卡：美英音标+发音+释义+收藏，左右箭头切换 |
| 整篇逐段翻译 | **批量接口**：多段合并一次请求（Google 保留分隔符）→ 按段拆分 |
| 正文页收藏 | 工具栏加收藏按钮（复用 bookmarks API） |
| 排版 | 段落间距、字号行距微调 |

### 翻译"快"的关键发现

**Google gtx 保留换行/分隔符**。测试确认：用 `@@@SEP@@@` 分隔多段合并翻译，分隔符原样保留、各段译文不混。因此**整篇 N 段 = 1 次 HTTP 往返**（0.66s 实测 3 段），比逐段请求（N 次往返）快一个数量级。

## 二、后端：批量翻译接口

`POST /api/dict/translate-batch`：
- `texts: list[str]`（≤30 段，总字数 ≤5000）
- 用 `@@@SEP@@@` 拼接 → Google 一次翻译 → `split(_SEP)` 拆回
- 段数不足时补空串对齐；Google 失败回退逐段 MyMemory
- 各段单独缓存 30 天（复用 `_TRANS_CACHE`）

## 三、前端

- **`KeywordCarousel`**：重点词轮播（滑动卡片组）。每张卡懒加载词典详情（`lookupWord`），显示美英音标、发音（有道音频）、释义（前 3 条）、收藏生词；左右箭头 + 进度指示。
- **`ArticleReader` 重构**：
  - "翻译全文/收起全文翻译"工具条 → `translateBatch` 一次翻译所有段落
  - 每段下方显示译文（灰底块），带"译文"收起/展开按钮（可逐段收起）
- **`ArticleDetailPage`**：重点词 pills → KeywordCarousel；工具栏加"收藏/已收藏"按钮。
- `lib/translate.ts`：批量翻译 API 封装（空段补位对齐）。

## 附：7 项反馈修复

用户实测后提出 7 项问题，逐一修复：

1. **翻译不消失、可全文/逐段并行**：重构状态模型——翻译结果持久保存（`translations` map），"翻译全文/收起全文"只切换 `expandAll`，"译文"按钮逐段切换（`collapsedSet`）。收起全文后译文不丢失，可随时逐段或全文再展开。
2. **轮播丑（卡片套卡片 + 高度不一）**：去掉嵌套卡片，改为**固定高度 h-44 容器**内每词一页，内容超出滚动；头部一行式（单词+美英发音+音标+收藏），不再卡片嵌套。
3. **朗读区分英/美音**：`speak()` 加 `accent` 参数（en-US/en-GB 选音色）；新组件 `SpeakButtons` 提供"美/英"两个独立发音按钮（有有道真实音频优先，无则 TTS）；应用在点词弹窗和重点词卡。
4. **详情页补来源**：元信息区加 `sourceLabel(article.source)`（VOA/卫报/大西洋）。
5. **进度条贴导航栏**：`top-14`→`top-16`（导航栏 h-16=64px），去掉背景色（只留填充线），不再和 border 叠成两根线。
6. **同步文章权限化**：后端 `POST /api/crawl` 要求登录 + `user.is_admin`；User 加 `is_admin` 字段 + migrate + seed 设 tester 为管理员；前端仅 admin 显示"同步外部文章"按钮。无 token 401、tester 200 验证通过。
7. **骨架屏匹配真实布局**：重写为杂志式（HERO 大块 + 左栏推荐/网格卡片骨架 + 右栏侧栏占位），匹配真实格局。**踩坑**：多次编辑导致 JSX 重复嵌套（两个主内容区 div），修复后骨架分支正确渲染。

### 踩坑记录

**JSX 重复嵌套**：骨架屏多次重构时，旧的主内容区块（左栏+搜索条）残留与新块叠加，导致 div 配平错乱（31 开 26 闭）。用 Python 脚本辅助配平检查定位，删除残留块后恢复正常。**教训：大块 JSX 重构时先看整体结构再动手，避免增量编辑造成嵌套重复。**

## 附 2：长篇翻译失败修复（分段限制）

### 现象

用户反馈：只有最初几篇 seed 寓言翻译成功，抓下来的文章（VOA/卫报/大西洋）都没成功。

### 根因

批量翻译接口有 `总字数超限（5000）` 硬限制。seed 寓言短、VOA 短文（莱特兄弟 2658 字符）在限制内；但长篇（The Open Boat 44 段 8252 字符、卫报/大西洋长文 6000-8000 字符）超限，返回 422 → 前端静默失败。

### 修复

`translate-batch` **自动分块**：
- 贪心凑块，每块累计 ≤ 4000 字符（`_CHUNK_LIMIT`，留余量给分隔符）
- 单段超长独立成块
- 每块一次 Google 请求，合并结果
- 输入上限 30 → 200 段

### 验证

- 之前 422 的 25 篇全部通过：VOA 44 段 8252 字符（9.9s）、卫报 23 段、大西洋 16 段，段数全部对齐
- 三个来源长文抽样全部 200 + 段数对齐
